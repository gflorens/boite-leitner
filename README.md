# Boîte de Leitner

Application de révision de cartes selon la méthode de Leitner, pensée pour la classe : un prénom par élève, deux sens de travail, un calendrier fixe par case (la case 1 à chaque séance, la case 2 toutes les 2 séances, etc.), séances les jours de classe.

Ouvrir l'application dans Chrome ou Edge, puis cliquer sur « Installer » dans la barre d'adresse. Elle fonctionne ensuite hors connexion. Les données restent sur l'ordinateur ; le panneau « Sauvegarde » permet de les enregistrer dans un fichier.
