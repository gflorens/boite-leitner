# Boîte de Leitner

## 👉 Ouvrir l'application : **[gflorens.github.io/boite-leitner](https://gflorens.github.io/boite-leitner/)**

### L'installer
- **PC (Chrome ou Edge)** : ouvrir le lien ci-dessus, puis cliquer sur l'icône « Installer » à droite de la barre d'adresse.
- **Mac (Safari)** : ouvrir le lien, puis menu **Fichier → Ajouter au Dock…**
- **Mac (Chrome ou Edge)** : comme sur PC.

Une fois installée, l'application se lance depuis le menu Démarrer (PC) ou le Dock (Mac), sans passer par GitHub. Elle fonctionne hors connexion.

### À savoir
Les prénoms, les séries et la progression des élèves restent sur l'ordinateur. Le panneau « Sauvegarde », en bas de l'écran d'accueil, permet de les enregistrer dans un fichier et de les restaurer sur un autre ordinateur.

---

Application de révision de cartes selon la méthode de Leitner, pensée pour la classe : un prénom par élève, deux sens de travail, un calendrier fixe par case (la case 1 à chaque séance, la case 2 toutes les 2 séances, etc.), séances les jours de classe, bibliothèque de séries pour le cycle 3.
